## The method on one page

The method is called charter, after the one thing it adds to a project: a small written charter that every unit of work cites and that machines check. `docs/method.md` is the full text; `docs/gates.md`, `docs/package.md`, `docs/migration.md` and `docs/trials/2026-09-11.md` carry the reference, the package, the migration and the trial.

- **Scope** (`charter/scope.md` in a project; template `package/charter/templates/scope.md`): what is sold, what is not, the assumptions, summarised from the signed devis. Out-of-scope paths are refused until a change request the owner approved covers them (rule R6, hard; `package/.charter/checks.py` `check_scope`).
- **Decisions** (`charter/decisions/<id>.md` in a project; template `package/charter/templates/decision.md`): one per file, with the case that justified it and when it stops applying. Code cites them with `charter:<id>`; a decision can carry a `check:` command. Citing a retired decision or breaking a check is refused (R1, hard; `package/.charter/checks.py` `check_decisions_text`, `run_decision_checks`).
- **Unit of work**: the tasket, unchanged for the two engines that dispatch it, plus optional keys (`scope`, `perimeter`, `decisions`, `kind`) and three sections: acceptance probes, evidence, an append-only log. `done` is refused without every probe checked and evidence that resolves (R9, hard). This is the ISA idea from upstream PAI carried on the tasket instead of a new document (E-12, E-13).
- **Size**: a file over its limit is frozen for growth until a split unit exists (R3, hard). Governance files have a lower limit; tcv2's 873-line `CLAUDE.md` is the case (E-6).
- **Perimeter**: an edit outside the unit's declared paths lands only with a note (R4, hard at commit; `package/.charter/checks.py` `check_perimeter`).
- **Deliverables** are anchored: a report, a PR description or a synthesis fails CI if a claim line has no anchor that resolves (R10, hard in CI; `package/.charter/checks.py` `check_anchors`, `package/.github/workflows/charter.yml`). This is the zero-hallucination guarantee, and it is a guarantee about pointers, not truth.
- **The gates run three times**: Claude Code hooks (`package/.claude/settings.json`, `package/.charter/hooks/`), the pre-commit hook (`package/.charter/githooks/pre-commit`, whichever agent commits), CI (`package/.github/workflows/charter.yml`, from a clean clone). Everything else warns and is logged to `.charter/state/log.jsonl` (`package/.charter/lib.py` `log_event`); the log is the promotion evidence.
- **`charter synth`** produces the progress synthesis from repository state and refuses to publish if it fails its own check (`package/.charter/bin/charter` `cmd_synth`). **`charter/ledger.jsonl`** records tokens and estimated cost per session and unit (`package/.charter/hooks/session_end.py`, `cmd_ledger`), so cost per accepted result is a query, not a guess.

### What hooks can enforce (E-7)

A `PreToolUse` hook sees the tool's arguments before they run and can deny with a reason that reaches the model (E-7); for Edit it sees `old_string` and `new_string`, so the post-edit content can be computed (`package/.charter/hooks/_common.py` `post_edit_text`). It does not see edits made by a Bash command, files added with `@` (E-7), or an Edit whose `old_string` is absent (Claude Code rejects that before hooks, trial T1c, `docs/trials/2026-09-11.md`). A `Stop` hook sees the final message and can hold the turn open once (E-7). Nothing in a session can enforce anything on a commit made by another harness; the git hook and CI can (`docs/trials/2026-09-11.md` § Direct exercise).

## The hard gates

Five, each justified by a failure a warning would not prevent (`docs/method.md` § The hard gates; reference in `docs/gates.md`): done needs evidence (the consumer of a status is a program, `~/Projects/tele-claude/services/group_automator.py:5059`); out-of-scope without approval (the video's discount that becomes a house rule); contradicting a decision (invisible in a diff review); frozen file (a warning has never shrunk a file); anchored deliverables (the reader is a person who cannot re-derive them). Each denial names its override, so no gate is a dead end; the Stop gate blocks once and reads `stop_hook_active`; every gate fails open on its own errors and logs it.

## Accepted results and the anchoring check

Real tests: exercise the public surface named by the criterion, fail without the change, run in CI from a clean clone without live credentials (`docs/method.md` § Accepted results). The anchoring check: `charter anchors` treats every prose line, list item or table row of 40 characters or more, or containing a digit, as a claim; an anchor is a `path:line` that exists, a bare path that exists, a git object that resolves, a URL, a `$ command` line, or an `E-n` into the document's own index; `(unverified)` and `(reported in ...)` are admitted; opinion sections are exempt. What it cannot cover is stated in `docs/method.md`: it checks that pointers resolve, not that they support the claim.

## What would falsify the method, and what I found

<!-- charter: opinion -->
For each headline rule and gate: the evidence that would show it wrong or not worth its cost, whether I found it, and what it changes.

- **R1, decisions with markers and checks.** Falsified if real decisions cannot be expressed as markers or checks. Partly found: tcv2's twenty rulings are operational prose about who does what ("whoever can run it, runs it", "the board finishes its two filed slices"), and none of the twelve I sampled is a grep. The `check:` field will be rare; the marker plus `binds:` is the working part, and it only catches a retired citation or a bound file without a marker. The rule still pays because the record itself is small and the index is handed to every session; its enforcement is weaker than Cursor's compile-checked references and I say so in the table.
- **R3, size limit.** Falsified if the limit blocks legitimate growth more than it prevents harm. Found in part: on orqueveaux, five of the eleven frozen files are test files that grow by nature, and the limit's origin (1,173 agents on one file in a swarm) is not this scale's problem; here the cost of a big file is context and readability. The rule stays because tcv2's `CLAUDE.md` and orqueveaux's 3,048-line `INFRASTRUCTURE.md` are exactly that cost, but the limit for tests is a decision for you (`size-limits` below).
- **R6, scope by path globs.** Falsified if in-scope and out-of-scope work share files. Found: orqueveaux's audit says C-3 (an in-scope fix in `app/services/webhook_processor.py`) "is also the foundation of upsell Package A" (`docs/AUDIT_AND_BUSINESS_REPORT_2026-06.md:58` in the clone). Where paths overlap, the gate degrades to "the unit cites a scope item", which is a warning. The rule still holds the cases that are separable (a new module, a new integration) and the change request remains the written place for the rest.
- **R9, done needs evidence.** Falsified if agents check boxes and paste evidence without running probes. Not observed in the trial: T6, T6b and T7 ran the probe and cited real commits. The gate checks shape, so the failure is possible; the answer is a `--probe` mode that re-runs each probe at commit, which I left as a follow-up because probes can be slow and flaky and that trade needs your call.
- **R10, anchors.** Falsified if the check produces false positives that make people exempt whole documents, or passes decorative anchors. One false positive found and fixed (C4). Decorative anchors pass, as stated. The count of `(unverified)` admissions per document is reported so a document that admits everything is visible.
- **Stop gate.** Falsified if it loops or if agents learn to paste a token anchor. It did not loop (T5). Token anchors were not observed but are cheap to produce; the gate is a nudge with a log, not a guarantee, and the report says so.
- **The premise that gates are needed at all.** Evidence for "less method": five of five first attempts were refused by Sonnet from the rules alone, at 0.035 to 0.044 USD each. Evidence against: with a plausible unit, the same model edited an out-of-scope file, contradicted a decision and set done without evidence, and only the gate stopped it; and the engines that dispatch taskets never read the rules. The gates stay, and there are five.
- **R11, the ledger.** Falsified if the estimate is far from the bill. Found: 0.1671 estimated against 0.1302 reported for one session, 28% apart, because the default price table is not Sonnet 5's. The measure is labelled an estimate and the price table is yours to set; headless runs record the reported figure.
