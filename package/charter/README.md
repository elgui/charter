# charter/

The written charter of this project. Machines check it; people own it.

| File | What it is | Who changes it |
|---|---|---|
| `scope.md` | What is sold, what is not, the assumptions. Summarised from the signed devis | The owner |
| `decisions/<slug>.md` | One design decision per file. Code cites it with `charter:<slug>` | Whoever settles it; status by the owner |
| `decisions/INDEX.md` | Generated by `charter decisions index` | Nobody |
| `changes/<slug>.md` | A change request for work outside the scope | Anyone proposes; only the owner approves |
| `config.json` | Track (`client` or `prototype`), owner, limits, probes, price estimates per model | The owner |
| `legacy-taskets.txt` | Taskets found at install without an acceptance section; the done gate lets them close with a warning | Written by the installer; entries removed by anyone, added by the owner |
| `ledger.jsonl` | Tokens and estimated cost per session and unit | `charter ledger` |
| `progress.md` | Generated by `charter synth --write` | Nobody |
| `templates/` | Templates for the files above and for a unit of work | The package |
| `VERSION` | Installed package version | The installer |

Units of work live in `.taskets/` (see `templates/unit.md`). Tooling lives in `.charter/`. The gate log and session records live in the git directory (`.git/charter/`), shared by worktrees and never committed.

Owner-only: `scope.md`, `config.json`, `legacy-taskets.txt`, the approval fields of change requests, the status of existing decisions, `kind: split` units, and `.charter/`. An agent's Edit or Write on them is refused unless Claude Code was started with `CHARTER_OWNER=1`.
